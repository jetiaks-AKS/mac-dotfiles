# del

Безопасная команда для удаления файлов и директорий в macOS.

## Использование

```bash
del <file-or-directory>
````

Пример:

```bash
del ~/Desktop/example-folder
```

Перед удалением команда запрашивает подтверждение.

## Возможности

* удаление файлов и директорий;
* рекурсивное удаление;
* подтверждение перед удалением;
* обработка macOS immutable-флага `uchg`;
* повторная попытка удаления после снятия `uchg`;
* удаление пустой директории, если содержимое уже было удалено.

## Подключение

Компонент подключается через корневой установщик:

```bash
cd ~/.mac-dotfiles
./install.sh
```

Или вручную:

```bash
source "$HOME/.mac-dotfiles/zsh/del/del.zsh"
```
