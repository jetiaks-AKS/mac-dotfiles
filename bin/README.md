# Утилиты обслуживания macOS

Набор небольших команд для проверки состояния и безопасной очистки macOS.

Компонент содержит две команды:

- `mccheck` — анализ системы без удаления данных;
- `mcclean` — консервативная очистка только заранее разрешённых категорий.

## mccheck

Безопасная проверка потенциально ненужных данных в macOS.

Команда работает только в режиме чтения и **ничего не удаляет**.

### Использование

```bash
mccheck
```

### Проверяет

- использование системного тома;
- использование тома Data;
- пользовательские кэши;
- кэши CLI-инструментов;
- пользовательскую Корзину;
- системную Корзину root;
- кэш Homebrew;
- временные файлы;
- пользовательские логи;
- данные Xcode и инструментов разработчика;
- резервные копии iPhone и iPad;
- кэши пакетных менеджеров;
- локальные снимки Time Machine;
- крупные файлы в Downloads.

В конце проверки выводится:

```text
CHECK COMPLETE — NOTHING WAS DELETED
```

## mcclean

Консервативная утилита для очистки macOS.

Удаляет данные только из заранее разрешённых мест и не затрагивает системные
базы macOS и пользовательские данные приложений.

### Пробный запуск

```bash
mcclean --dry-run
```

Показывает предполагаемые действия без удаления данных.

### Реальная очистка

```bash
mcclean
```

Перед началом реальной очистки команда запрашивает подтверждение.

### Что может очищаться

- кэш сред выполнения Codex;
- кэш обновлений Termius;
- устаревшие данные Homebrew через `brew cleanup`;
- пользовательская Корзина;
- системная Корзина root.

### Что намеренно не очищается

Утилита не удаляет:

- системные базы macOS;
- `/private/var/db`;
- виртуальную память `/private/var/vm`;
- локальные снимки Time Machine;
- `Application Support`;
- `Containers`;
- `Group Containers`;
- Keychains;
- другие потенциально важные пользовательские и системные данные.

## Установка

Команды устанавливаются корневым установщиком репозитория:

```bash
cd ~/.mac-dotfiles
./install.sh
```

Установщик создаёт ссылки:

```text
/usr/local/bin/mccheck -> ~/.mac-dotfiles/bin/mccheck
/usr/local/bin/mcclean -> ~/.mac-dotfiles/bin/mcclean
```

После этого команды доступны из любого каталога:

```bash
mccheck
mcclean --dry-run
mcclean
```
