# mac-dotfiles

Личные настройки и небольшие инструменты для macOS.

Репозиторий хранит полезные shell-функции, алиасы и небольшие утилиты,
которые можно воспроизводимо установить на новый Mac.

## Установка

```bash
git clone git@github.com:jetiaks-AKS/mac-dotfiles.git ~/.mac-dotfiles
cd ~/.mac-dotfiles
./install.sh
```

После установки:

```bash
source ~/.zshrc
```

## Структура

Каждый самостоятельный компонент хранится отдельно и содержит собственную документацию.

```text
mac-dotfiles/
├── .gitignore
├── README.md
├── install.sh
├── bin/
│   ├── mccheck
│   ├── mcclean
│   └── README.md
└── zsh/
    ├── del/
    │   ├── del.zsh
    │   └── README.md
    └── workdirs/
        ├── workdirs.zsh
        └── README.md
```

## Компоненты

### `del`

Безопасная команда для удаления файлов и директорий в macOS.

Документация:

```text
zsh/del/README.md
```

### `workdirs`

Команды для быстрого перехода между рабочими директориями.

Документация:

```text
zsh/workdirs/README.md
```

### `mccheck` и `mcclean`

Утилиты для проверки состояния и безопасной очистки macOS.

- `mccheck` — анализирует потенциально ненужные данные и ничего не удаляет;
- `mcclean` — выполняет консервативную очистку только разрешённых категорий.

Документация:

```text
bin/README.md
```

## Принципы

- Простота
- Воспроизводимость
- Идемпотентность
- Безопасность
- Каждый компонент — отдельно

Проект развивается постепенно по мере появления действительно полезных инструментов.
