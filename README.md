# mac-dotfiles

Личные настройки и небольшие инструменты для macOS.

Этот репозиторий содержит переиспользуемые функции Zsh, алиасы и небольшие
CLI-инструменты, которые делают ежедневную работу на Mac удобнее.

---

## Содержимое

### Zsh

- `del` — безопасное рекурсивное удаление файлов и папок с подтверждением
  и обработкой macOS immutable-флагов.

---

## Установка

Клонировать репозиторий:

```bash
git clone git@github.com:jetiaks-AKS/mac-dotfiles.git ~/.mac-dotfiles
````

Подключить нужные компоненты в `~/.zshrc`:

```bash
source "$HOME/.mac-dotfiles/zsh/del.zsh"
```

Перезагрузить конфигурацию:

```bash
source ~/.zshrc
```

После этого команда `del` будет доступна в терминале.

## Философия

Это персональный репозиторий инструментов для macOS.

Главная цель — хранить полезные настройки, функции и небольшие инструменты
в одном месте, чтобы их было легко восстановить на другом Mac.

Репозиторий развивается постепенно: новые полезные инструменты и настройки
добавляются по мере необходимости.

В репозитории **не должны храниться**:

* пароли;
* токены;
* SSH private keys;
* credentials;
* секреты;
* другие персональные или машинно-зависимые данные.
