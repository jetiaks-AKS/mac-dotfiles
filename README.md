# mac-dotfiles

Личные настройки и небольшие инструменты для macOS.

Репозиторий хранит полезные shell-функции, алиасы и небольшие инструменты,
которые можно воспроизводимо установить на новый Mac.

## Установка

```bash
git clone git@github.com:jetiaks-AKS/mac-dotfiles.git ~/.mac-dotfiles
cd ~/.mac-dotfiles
./install.sh
````

После установки:

```bash
source ~/.zshrc
```

## Структура

Каждый самостоятельный компонент находится в отдельной директории и содержит
собственную документацию.

```text
mac-dotfiles/
├── .gitignore
├── README.md
├── install.sh
└── zsh/
    └── del/
        ├── del.zsh
        └── README.md
```

## Принципы

* Простота
* Воспроизводимость
* Идемпотентность
* Безопасность
* Каждый компонент — отдельно

Проект развивается постепенно по мере появления действительно полезных
инструментов.
